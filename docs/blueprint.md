# **App Name**: Natura Skincare

## Core Features:

- Product Listing: Display all available skincare products in a clean, mobile-first grid layout.
- Product Details: Show detailed information for each product, including description, ingredients, usage instructions, and suitable skin type.
- Add to Cart: Allow users to add products to a shopping cart for purchase.
- Contact Form: A simple form allowing users to send email inquiries to the Natura Skincare support team.
- Customer Testimonials Display: Display authentic customer testimonials to build trust and demonstrate the effectiveness of the products.
- Firestore Product Catalog: Store and manage product information, including name, description, images, price, and inventory.
- AI Product Recommendation Tool: Uses past shopping behavior of the user to determine what products might interest them and makes recommendations on the home page. 

## Style Guidelines:

- Primary color: Sage Green (#A7D1AB), a soft, earthy tone that evokes nature and calmness.
- Background color: Warm Beige (#F5F5DC), providing a light and breathable backdrop.
- Accent color: Soft Brown (#A67B5B), used subtly for highlights and call-to-action elements.
- Body text font: 'Inter', a simple, highly readable sans-serif.
- Headline font: 'Alegreya', a humanist serif font to give an elegant, intellectual, contemporary feel.
- Use simple, line-based icons representing natural elements and skincare benefits.
- Mobile-first, clean layout with clear visual hierarchy to guide the user through the site intuitively.
- Subtle fade-in animations on scroll to add a smooth, gentle feel without being distracting.
